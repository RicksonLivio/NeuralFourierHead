# Paper to code map

Where each definition, result and number of the paper (*Neural Fourier Head: an identifiable trend–seasonal decomposition
layer for interpretable multi-step forecasting*, submitted to ESANN 2027, under review) lives in this repository.

Conventions:

- `file::symbol` is a function, class or method in the file; `file#a/b/c` is a key path inside a JSON result
  (`/` separates keys). Both forms are checked by `tests/test_paper_to_code.py`: the file must exist, the symbol must
  appear in it and the key path must resolve.
- "Library" is `nfh` (source in `experimentation/src/nfh/`, installed by `uv sync`). "Study" is the code under `src/` that
  produced the paper's numbers. Variable names in the study and in some docstrings are in Portuguese
  (`janela` = window, `semente` = seed, `cabeça` = head, `densa` = dense, `ajuste` = adjustment).
- "Command" is what recomputes the number from the stored results in minutes on a CPU (Level 1 of `REPRODUCE.md`).
  Retraining (Levels 2 and 3) is slower and gives slightly different numbers (`REPRODUCE.md`).
- Values are quoted as the paper rounds them; the JSON holds the unrounded ones (a fraction such as `-0.0059` is `-0.59%`).
